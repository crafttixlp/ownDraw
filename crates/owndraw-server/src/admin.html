Neue Mitteilung

Aktive Mitteilungen erscheinen beim Start der Web-App, auch für Gäste. Sie erscheinen bei jedem Laden der Seite erneut, solange sie aktiv sind; Wegklicken gilt nur bis zum nächsten Neuladen.

Das Board erscheint schreibgeschützt in der Mitte der Mitteilung, gut für Bilder, Updates und News. Besucher sehen es auch ohne Zugriff auf das Board; Änderungen am Board sind sofort sichtbar.

Wartungsmodus

Im Wartungsmodus sehen Nutzer und Gäste eine Wartungsseite. Speichern, Laden und gemeinsames Bearbeiten auf dem Server sind gesperrt, offene Live-Verbindungen werden getrennt. Administratoren können weiterarbeiten. Die statische Web-App ohne Server ist nicht betroffen.

Ohne Angabe bleibt der Wartungsmodus aktiv, bis du ihn beendest. Besucher sehen die Zeit als voraussichtliches Ende.
