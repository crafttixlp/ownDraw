Wartungsmodus

Im Wartungsmodus sehen Nutzer und Gäste eine Wartungsseite. Speichern, Laden und gemeinsames Bearbeiten auf dem Server sind gesperrt, offene Live-Verbindungen werden getrennt. Administratoren können weiterarbeiten. Die statische Web-App ohne Server ist nicht betroffen.

Ohne Angabe bleibt der Wartungsmodus aktiv, bis du ihn beendest. Besucher sehen die Zeit als voraussichtliches Ende.
