Zeichnen in Ebenen und auf Seiten · Version __OWNDRAW_VERSION__

Dein Browser stellt gerade keine Grafik für Webseiten bereit (WebGL und Canvas). Meist ist die Hardwarebeschleunigung ausgeschaltet. So schaltest du sie ein:

  1. Chrome / Edge: Einstellungen → System → „Grafikbeschleunigung verwenden, wenn verfügbar“ einschalten, dann den Browser neu starten.
  2. Firefox: Einstellungen → Allgemein → Leistung → „Hardwarebeschleunigung verwenden, wenn verfügbar“ einschalten (ggf. erst „Empfohlene Leistungseinstellungen verwenden“ abwählen), dann neu starten.
  3. Safari: auf eine aktuelle Version aktualisieren.

Hilft das nicht: Grafiktreiber aktualisieren oder einen anderen Browser versuchen.

Bitte lade die Seite neu. Hilft das nicht, verwende einen aktuellen Browser (Chrome, Edge, Firefox oder Safari) mit eingeschaltetem JavaScript.
