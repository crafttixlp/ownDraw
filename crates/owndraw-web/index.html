Dein Browser kann keine Grafik für Webseiten anzeigen (WebGL und Canvas). Meist ist die Hardwarebeschleunigung ausgeschaltet. So schaltest du sie ein:

  1. Chrome / Edge: Einstellungen → System → „Grafikbeschleunigung verwenden, wenn verfügbar“ aktivieren und den Browser neu starten.
  2. Firefox: Einstellungen → Allgemein → Leistung → „Hardwarebeschleunigung verwenden, wenn verfügbar“ aktivieren (falls nötig zuerst „Empfohlene Leistungseinstellungen verwenden“ abwählen) und neu starten.
  3. Safari: auf die aktuelle Version aktualisieren.

Hilft das nicht, aktualisiere den Grafiktreiber oder probiere einen anderen Browser.
