# UI-Checkliste: alte Funktion → neuer Ort (WP6)

| Alt (Rust 3.0) | Neu |
|---|---|
| Board-Übersicht, Kacheln | Start: „Zuletzt geöffnet“ (Kacheln mit Vorschau) |
| „Neues Board“ | Start: „Neu“ (Knopf oder Kachel) → Neu-Dialog (Unendlich/Seiten, Format, Hintergrund, Name, Speicherort) |
| „Board importieren“ (.owndraw) | Start: „Öffnen …“ (.owndraw/.xopp), Drag & Drop, Kommandozeile |
| Kachel: Umbenennen / Duplizieren / Exportieren / Löschen | Umbenennen: Editor (Titel antippen oder ⋯ → Umbenennen); Duplizieren/Exportieren: ⋯ → Kopie speichern unter …; Löschen: Datei im Dateimanager, Kachel: „Aus der Liste entfernen“ |
| Zurück zur Übersicht | Editor oben links „‹“ bzw. ⋯ → Schließen |
| Titel antippen → Umbenennen | unverändert (oben links) und ⋯ → Umbenennen |
| Rückgängig / Wiederholen | Editor oben rechts, immer sichtbar (Strg+Z / Strg+Y) |
| Formerkennung (3 Modi, Klick-Zyklus) | Stift/Marker-Optionen → Formerkennung: Halten / Immer / Aus |
| Hintergrund wechseln (Zyklus) | ⋯ → Hintergrund (Punkte/Raster/Linien/Leer; im Seitenmodus Blanko/Liniert/Kariert/Punktiert je Seite) |
| Hell/Dunkel (Board) | ⋯ → Board: hell/dunkel; App-Theme: Einstellungen |
| Ebenen-Panel | ⋯ → Ebenen (Compact Vollbild, Medium schwebend, Expanded angedockt) |
| Bild importieren | Werkzeug „Bild“ (Taste I), Ebenen-Panel → Bild, Drag & Drop |
| Website-Vorschau | ⋯ → Website-Vorschau |
| Exportieren PNG / PDF / ZIP (Strg+E) | ⋯ → Export (Strg+E öffnet das ⋯-Menü) |
| Ebene als PNG | Ebenen-Panel → Zeile → Als PNG exportieren; ⋯ → Aktive Ebene als PNG |
| Zoom-Anzeige / Alles zeigen (0) | Oben rechts (Medium/Expanded) bzw. ⋯ → Alles zeigen |
| Stift, Marker, Radierer, Auswahl, Form, Text | Werkzeugleiste (P, M, E, S, R, T) |
| Notiz (N) | Text-Optionen → Haftnotiz (Taste N) |
| Radierer-Modus (Klick-Zyklus) | Radierer-Optionen → Modus |
| Auswahl-Modus Lasso/Rechteck (Klick-Zyklus) | Auswahl-Optionen → Modus |
| Form-Art Rechteck/Ellipse/Linie/Pfeil (Zyklus) | Form-Optionen (neu: Maschinenbau-Pfeil) |
| 8 Farben, 4 Breiten | Optionen des Werkzeugs (Popover bzw. Bottom-Sheet) |
| Auswahl-Aktionsleiste (Kopieren … Löschen) | unverändert bei aktiver Auswahl (unten mittig) |
| Strg+S | speichert sofort (Autosave 2 s nach Änderung, beim Schließen, bei Pause) |
| Zoom/Pan, Leertaste, Mausrad, Touch | unverändert |
| – (neu) | Seitenleiste im Seitenmodus, Einstellungen (⋯ bzw. Start), Kopie speichern unter, Xournal++ exportieren |
